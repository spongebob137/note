# Vim搜索替换与批量编辑

## 总结

日志定位主要使用搜索，脚本修改主要使用带范围和确认的替换。批量操作前先限定范围、预览匹配并保留撤销路径，能显著降低误改风险。

## 搜索

| 命令 | 作用 |
|---|---|
| /ERROR | 从当前位置向下搜索 |
| ?ERROR | 从当前位置向上搜索 |
| n | 沿当前搜索方向继续 |
| N | 沿当前搜索方向的反方向继续 |
| :nohlsearch | 取消搜索高亮 |

注意：n表示重复当前方向。使用?开始向上搜索后，n仍然继续向上。

## 替换

    :s/old/new/

当前行只替换第一处。

    :s/old/new/g

当前行替换所有匹配。

    :%s/old/new/gc

整个文件逐项确认替换：

| 部分 | 含义 |
|---|---|
| % | 整个文件范围，不是必带 |
| s | substitute，替换 |
| g | 每行替换所有匹配 |
| c | 每处替换前确认 |

确认按键：

| 按键 | 作用 |
|---|---|
| y | 替换当前项 |
| n | 跳过当前项 |
| a | 替换剩余全部 |
| q | 停止替换 |
| l | 替换当前项后停止 |

指定范围：

    :10,20s/old/new/gc

## 按匹配行执行命令

预览：

    :g/ERROR/p

删除：

    :g/ERROR/d

限定前200行：

    :1,200g/ERROR/d

这里开头的g表示查找所有匹配行并执行后续命令，不是替换命令末尾的g标志。

## 可视模式

| 按键 | 选择方式 |
|---|---|
| v | 按字符选择 |
| V | 按整行选择 |
| Ctrl+V | 矩形列选择 |
| Ctrl+Q | 某些终端中替代Ctrl+V |

批量增加前缀的一般过程：

1. Ctrl+V进入可视块。
2. 使用j/k/h/l选中矩形区域。
3. 按大写I。
4. 输入注释前缀。
5. 按Esc把输入应用到所有选中行。

批量删除列：选中列后按d。

## 易错点

- / ERROR会搜索前导空格加ERROR；一般写/ERROR。
- %表示全文范围，并不是冒号命令必带前缀。
- 替换末尾g不是递归。
- 大型文件使用不带c的全文替换风险很高。
- 可视块输入完成后必须按Esc，修改才应用到全部选中行。

## 数字后端应用

- 搜索ERROR、WARN、cell、pin和阶段名称。
- 修改Tcl/SDC中的路径、corner或变量名。
- 批量增加或删除脚本注释。
- 删除仅在个人副本中确认无用的日志行。

## 自检

- 能解释/、?、n、N。
- 能完整拆解:%s/old/new/gc。
- 能区分两种g的含义。
- 能使用可视块批量注释并撤销。
