# Vim移动与编辑

## 总结

Vim高效编辑依赖普通模式下的定位命令和精确的插入入口。优先掌握 gg/G、0/$、w/e/b 以及 i/I/a/A/o/O，并注意大写字母和数字零的区别。

## 基本移动

| 按键 | 作用 |
|---|---|
| h | 左移 |
| j | 下移 |
| k | 上移 |
| l | 右移 |
| w | 下一个单词开头 |
| e | 当前或下一个单词结尾 |
| b | 上一个单词开头 |
| 0 | 行的最左端 |
| ^ | 行的第一个非空字符 |
| $ | 行尾 |
| gg | 文件第一行 |
| G | 文件最后一行 |
| nG | 文件第n行 |
| Ctrl+f | 向下翻页 |
| Ctrl+b | 向上翻页 |

## 插入入口

| 按键 | 作用 |
|---|---|
| i | 在光标前插入 |
| a | 在光标后插入 |
| I | 在本行第一个非空字符前插入 |
| A | 在本行末尾插入 |
| o | 在当前行下方新建一行 |
| O | 在当前行上方新建一行 |

每次完成输入后按Esc回到普通模式。

## 替换与修改

| 按键 | 作用 |
|---|---|
| r | 替换光标所在的一个字符 |
| R | 连续替换，直到按Esc |
| C | 删除光标到行尾并进入插入模式 |
| x | 删除光标所在字符 |
| X | 删除光标前一个字符 |

## 易错点

- I 是大写字母i，表示行首插入。
- O 是大写字母o，表示上方新建行。
- 0 是数字零，表示移动到最左端。
- w与e是两个独立命令，不是一个组合命令。
- G前面的数字是行号，例如100G跳到第100行。

## 数字后端应用

- 快速跳转报告末尾判断任务是否完成。
- 用单词移动浏览长cell、pin和net名称。
- 在Tcl命令行首尾快速补充参数或重定向。

## 自检

- 能不使用方向键完成移动。
- 能解释i与a、I与A、o与O的区别。
- 能定位第一行、最后一行和指定行。
