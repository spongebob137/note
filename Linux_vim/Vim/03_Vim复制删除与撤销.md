# Vim复制删除与撤销

## 总结

Vim的复制、删除和粘贴以寄存器为核心。yy复制整行，dd删除整行且同时把内容放入寄存器，p/P负责粘贴；u和Ctrl+r用于回退和恢复操作。

## 复制

| 命令 | 作用 |
|---|---|
| yy | 复制当前行 |
| 3yy | 从当前行开始复制3行 |
| yw | 复制一个单词范围 |

## 粘贴

| 命令 | 作用 |
|---|---|
| p | 粘贴到光标后；整行内容粘到下一行 |
| P | 粘贴到光标前；整行内容粘到上一行 |

## 删除或剪切

| 命令 | 作用 |
|---|---|
| dd | 删除当前行 |
| 5dd | 删除当前行开始的5行 |
| D | 删除光标至行尾 |
| dG | 删除当前行至文件结尾 |
| dw | 删除光标至单词末尾 |
| x | 删除当前字符 |
| X | 删除前一个字符 |

删除内容通常会进入Vim寄存器，因此dd后可以用p粘贴回来。Vim中的删除往往同时具有剪切效果。

## 撤销、重做与重复

| 命令 | 作用 |
|---|---|
| u | 撤销上一次修改 |
| Ctrl+r | 重做被撤销的修改 |
| . | 重复上一次修改动作 |

示例逻辑：

    3yy
    G
    p
    3dd
    u
    Ctrl+r

## 易错点

- 3yy、5dd是依次按键，不是组合键。
- Ctrl+r才是同时按下的组合键。
- dd删除后立刻执行其他复制或删除，默认寄存器内容可能被替换。
- 在大型日志末尾误按p可能插入大量内容，应及时u或使用:q!退出。

## 数字后端应用

- 复制相似的Tcl命令并修改参数。
- 删除废弃的约束或报告命令。
- 使用撤销验证批量操作，再决定是否保存。

## 自检

- 能复制3行并粘贴到末尾。
- 能删除粘贴内容并撤销、重做。
- 能解释dd后为什么仍可使用p。
