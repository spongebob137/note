# Vim模式与文件

## 总结

Vim启动后默认处于普通模式。输入文字前必须进入插入模式；保存退出等操作在命令行模式完成。不确定当前模式时先按Esc，是最重要的自救动作。

## 工作模式

| 模式 | 进入方式 | 用途 |
|---|---|---|
| 普通模式 | 启动默认；按Esc返回 | 移动、复制、删除、搜索入口 |
| 插入模式 | i、I、a、A、o、O | 输入文字 |
| 命令行模式 | 普通模式按冒号 | 保存、退出、替换、设置 |
| 可视模式 | v、V、Ctrl+V | 选择字符、行或矩形列 |

## 打开文件

    vim filename

- 文件存在：载入文件。
- 文件不存在：打开新缓冲区，保存后才真正创建文件。
- vim filename 中 filename 是命令参数。

## 保存与退出

| 命令 | 作用 |
|---|---|
| :w | 保存，不退出 |
| :q | 退出；有未保存修改时拒绝 |
| :wq | 保存并退出 |
| :q! | 放弃未保存修改并退出 |
| ZZ | 普通模式下保存并退出 |
| :w new_file | 把当前内容写到另一文件 |

感叹号表示强制执行，但不能绕过Linux文件权限。

## 行号

    :set number
    :set nu
    :set nonumber
    :set nonu

跳转指定行：

    :100
    100G

## Vim复制与系统剪贴板

Vim内部复制：

    yy
    p

全文选中并复制到Vim寄存器：

    ggVGy

复制到系统剪贴板需要Vim带有 clipboard 支持：

    ggVG"+y
    :%yank +

检查支持情况：

    vim --version | grep clipboard

## 易错点

- 终端中的Ctrl+C通常是中断，不是Vim复制。
- 中文冒号不能进入Vim命令行模式，必须使用英文半角冒号。
- :q! 会丢弃从上次保存以来的所有修改。
- 打开公共项目文件时不要随意保存；优先使用个人副本。

## 数字后端应用

- 打开和修改 Tcl、SDC、CDL、配置文件。
- 快速阅读日志和报告。
- 在个人副本上修改公共流程脚本。

## 自检

- 能解释四种模式。
- 能保存退出或放弃修改。
- 能判断新文件何时真正写入磁盘。
- 能区分Vim内部寄存器与系统剪贴板。
