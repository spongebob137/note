# Linux 与 Vim 重点速查

## 总结

入门阶段最重要的是路径判断、修改前确认、Vim模式切换、grep检索，以及区分通配符、正则、覆盖写入和追加写入。真实项目中优先保证原文件安全，再追求命令速度。

## 必须熟练

| 类别 | 内容 |
|---|---|
| 路径 | pwd、ls、cd、绝对路径、相对路径、.、..、~ |
| 文件 | mkdir、touch、cp、mv、rm |
| 查看 | cat、head、tail、less |
| 查找 | find、grep |
| 数据流 | 管道、覆盖重定向、追加重定向 |
| Vim | Esc、i/a/o、:wq、:q!、yy/dd/p、u、搜索 |
| 文本处理 | grep -n/-i/-v/-E、sed替换、awk字段 |

## 高频符号

| 符号 | 含义 |
|---|---|
| . | 当前目录；正则中为任意一个字符 |
| .. | 上一级目录 |
| ~ | 家目录 |
| * | Shell中匹配任意数量文件名字符；正则中重复前一元素 |
| ? | Shell中匹配一个文件名字符；ERE中前一元素可有可无 |
| \| | 将左侧命令输出交给右侧命令 |
| > | 覆盖写入 |
| >> | 追加写入 |
| < | 从文件读取标准输入 |
| $ | Shell变量值；正则行尾；Vim行尾 |
| # | Shell脚本注释 |

## Vim速查

    i I a A o O      进入插入模式
    Esc              返回普通模式
    gg G nG          首行、末行、第n行
    0 $              行首、行尾
    yy nyy p P       复制和粘贴
    dd ndd D dG      删除
    u Ctrl+r .       撤销、重做、重复
    /word ?word      向下、向上搜索
    n N              同方向、反方向继续搜索
    :w :q :wq :q!   保存和退出

## 高风险操作

    rm -rf
    chmod -R
    sed -i
    command > existing_file

使用前必须确认：

    pwd
    ls -l target

## 核心易错点

- cd .. 中必须有空格；cd.. 会被当作命令名。
- 当前在 reports 中时，ls reports 查找的是 reports/reports。
- 选项含义依赖具体命令：ls -l 是详细列表，wc -l 是统计行数。
- grep中的 . 不是字面句点；字面句点写成 \.。
- > 会清空旧内容，>> 才会追加。
- sed默认不修改文件，只有 -i 才原地修改。
- awk的 $1 是字段变量，"$1" 是普通文字。
