# Linux权限与安全操作

## 总结

权限决定谁能读取、修改和执行文件。目录的r/w/x含义与普通文件不同。chmod、rm、覆盖重定向和sed -i会直接改变状态，真实项目中必须先确认路径和影响范围。

## ls详细信息

    ls -ld new_dir

示例：

    drwxr-xr-x 2 user group 0 Jul 28 15:31 new_dir

字段：

| 字段 | 含义 |
|---|---|
| d | 类型为目录；普通文件为- |
| rwxr-xr-x | 所有者、用户组、其他用户权限 |
| 2 | 硬链接数 |
| user | 所有者 |
| group | 所属组 |
| 0 | 目录自身元数据大小，不是内容总大小 |
| 时间 | 最后修改时间 |
| new_dir | 名称 |

## rwx含义

普通文件：

| 权限 | 含义 |
|---|---|
| r | 读取内容 |
| w | 修改内容 |
| x | 执行文件 |

目录：

| 权限 | 含义 |
|---|---|
| r | 查看目录项名称 |
| w | 创建、删除或重命名目录项 |
| x | 进入和穿越目录 |

## 数字权限

    r = 4
    w = 2
    x = 1

示例：

    755 = rwxr-xr-x
    644 = rw-r--r--

修改：

    chmod u+x file
    chmod u-x file
    chmod 644 file

## rm

    rm -i file
    rm -ri directory

| 选项 | 含义 |
|---|---|
| -i | 删除前询问 |
| -r | 递归处理目录 |
| -f | 强制且不询问 |

rm -rf是高风险组合，不用于公共项目或未经确认的计算路径。

## 修改前检查

    pwd
    ls -ld target
    ls -l target

建议工作方式：

    项目原文件：只读
    个人原始副本：保留
    个人工作副本：允许修改

## 易错点

- ls -l directory显示内部内容；ls -ld directory显示目录本身。
- 目录有w权限不代表其中每个文件都有w权限。
- chmod -R会递归修改整个目录树。
- 删除一个硬链接名称不会立即释放数据，所有硬链接都删除后才可能释放。

## 数字后端应用

- 检查Tcl脚本是否可读或可执行。
- 保证共享flow脚本不被个人练习误改。
- 对个人副本使用sed -i前保留备份。

## 自检

- 能拆解drwxr-xr-x。
- 能计算755和644。
- 能说明目录x权限的作用。
- 能列出至少三条高风险命令。
