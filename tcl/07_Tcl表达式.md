# 07 Tcl表达式

## 总结

【重点】expr用于计算表达式，推荐始终把表达式放在花括号中。必须熟练算术、比较和逻辑运算，掌握整数除法与浮点除法的区别；位运算和大部分数学函数了解即可。

对应教程第14–17页“表达式”。

## 1. expr

推荐写法：

    expr {$training_x + 100}

花括号防止外层解释器提前处理，expr收到完整表达式后再完成变量读取和计算。

不推荐旧式写法：

    expr $training_x+100

## 2. 数值

整数：

    expr {10 + 20}

实数：

    expr {2.5 + 1.2}

科学计数：

    expr {6e4}

十六进制：

    expr {0x10}

【易错】旧版Tcl可能把以0开头的整数视为八进制。普通十进制数不要随意添加前导0。

## 3. 算术运算

| 运算符 | 含义 | 重要性 |
|---|---|---|
| + | 加 | 【重点】 |
| - | 减或取负 | 【重点】 |
| * | 乘 | 【重点】 |
| / | 除 | 【重点】【易错】 |
| % | 整数取余 | 【常用】 |

整数除法：

    expr {5 / 2}

结果：

    2

浮点除法：

    expr {5.0 / 2}

结果：

    2.5

## 4. 比较运算

| 运算符 | 含义 |
|---|---|
| < | 小于 |
| > | 大于 |
| <= | 小于等于 |
| >= | 大于等于 |
| == | 相等 |
| != | 不相等 |
| eq | 字符串相等 |
| ne | 字符串不等 |

数值比较：

    expr {$training_wns < 0}

字符串比较推荐eq和ne：

    expr {$training_stage eq "cts"}

结果为1表示条件成立，0表示条件不成立。

## 5. 逻辑运算

| 运算符 | 含义 |
|---|---|
| && | 逻辑与 |
| || | 逻辑或 |
| ! | 逻辑非 |

示例：

    expr {($training_wns < 0) || ($training_tns < 0)}

任一条件成立时返回1。

## 6. 优先级

    expr {1 + 2 * 3}

结果为7，因为乘法优先。

    expr {(1 + 2) * 3}

结果为9。

【重点】复杂表达式主动使用小括号，不依赖记忆完整优先级表。

## 7. 三目运算

    expr {$training_wns < 0 ? "VIOLATED" : "MET"}

条件为真返回VIOLATED，否则返回MET。

【常用】适合生成简单状态文字，但复杂分支应使用后续学习的if命令。

## 8. 数学函数

数字后端较常用：

| 函数 | 含义 | 重要性 |
|---|---|---|
| abs(x) | 绝对值 | 【常用】 |
| round(x) | 四舍五入到整数 | 【常用】 |
| floor(x) | 向下取整 | 【常用】 |
| ceil(x) | 向上取整 | 【常用】 |
| int(x) | 截断为整数 | 【常用】【易错】 |
| double(x) | 转为浮点值 | 【常用】 |
| sqrt(x) | 平方根 | 【了解】 |
| pow(x,y) | x的y次方 | 【了解】 |

三角函数、双曲函数和对数函数当前阶段了解即可。

## 9. 位运算

    <<
    >>
    &
    |
    ^
    ~

【了解】主要用于掩码、位字段或底层数据处理，普通后端流程脚本使用频率较低。

## 10. 数字后端示例

    set training_wns -0.12
    set training_tns -3.50

    set training_has_violation [expr {
        ($training_wns < 0) || ($training_tns < 0)
    }]

    set training_status [expr {
        $training_has_violation ? "VIOLATED" : "MET"
    }]

## 11. 易错点

- 忘记expr，得到的只是表达式字符串。
- expr表达式未使用花括号。
- 5/2使用整数除法得到2。
- 字符串比较仍习惯使用数值运算思路；字符串优先使用eq和ne。
- 复杂表达式不加括号，错误理解优先级。
- 使用前导0导致旧版Tcl按八进制解释。

## 12. 自检

- 能解释expr为什么使用花括号。
- 能区分整数除法和浮点除法。
- 能写数值比较、字符串比较和逻辑组合。
- 能根据WNS和TNS生成状态值。
