- 教程示例后的 `//` 是讲解文字，不是Tcl注释。
- 所有练习变量使用 `training_` 前缀，避免和EDA工具变量混淆。

## 当前核心结论

```text
一条Tcl命令 = 命令名 + 参数单词
$var          = 变量置换
[command]     = 命令置换
\             = 反斜杠置换或命令续行
```
