## 使用约定

- 教程示例中的 `%` 是提示符，不需要输入。
- `fc_shell>` 是当前EDA Shell提示符，也不属于命令内容。
- 教程示例后的 `//` 是讲解文字，不是Tcl注释。
- 所有练习变量使用 `training_` 前缀，避免和EDA工具变量混淆。
- 教程较旧，笔记保留原章节顺序，同时采用较安全的现代Tcl写法。

快速检索入口：[00_Tcl重点速查.md](00_Tcl重点速查.md)

重要性标记：

- 【重点】：必须掌握，后续章节和工作中会反复使用。
- 【常用】：数字后端脚本中使用频率较高。
- 【易错】：容易产生错误结果或脚本故障。
- 【了解】：知道用途，需要时查阅即可。

## 当前核心结论

```text
一条Tcl命令 = 命令名 + 参数单词
$var          = 变量置换
[command]     = 命令置换
\             = 反斜杠置换或命令续行
```
