# 学习问题索引

## 总结

本目录按主题记录实操过程中真正遇到的问题。每个问题先写直接结论，再保留错误命令、原因、正确写法和验证结果，方便以后用关键词检索。

## 文件

- [Tcl问题.md](Tcl问题.md)：Tcl 语法、List、控制流、过程及 EDA Tcl 问题。
- [LSF问题.md](LSF问题.md)：任务提交、资源参数和状态判断问题。
- [Makefile问题.md](Makefile问题.md)：目标、依赖、recipe 和执行顺序问题。

## 记录格式

```text
问题：执行了什么，出现了什么现象？
结论：最短的正确答案。
原因：命令如何被解释。
正确写法：可直接验证的命令。
验证：实际输出或检查方法。
```
